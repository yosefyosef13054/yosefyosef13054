## About me

Senior Flutter developer focused on shipping production mobile apps and integrating them with modern AI systems — LLMs, RAG pipelines, and ChatGPT-style assistants. I like the seam where a polished Flutter UI meets a real backend doing real work: vector search, retrieval, tool use, and agentic flows. Most of my recent work has been building integration-ready AI products that teams can actually drop into their stack.

## What I do

- **Flutter mobile apps** — cross-platform iOS/Android apps with clean architecture, state management, and CI-friendly delivery.
- **AI-powered features** — LLM integrations, RAG over private data, prompt and tool design, and small agentic systems that do useful work end-to-end.
- **Backend integration** — Laravel/PHP services, REST and streaming APIs, auth, queues, and the glue that connects mobile + AI + data.
